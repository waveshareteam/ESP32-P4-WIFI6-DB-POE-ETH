# mipi_dsi

[简体中文](README_ZH.md)

## Function

Display color bars and exercise the DSI panel backlight.

## Hardware requirements

Development board and compatible DSI panel.

## How to run

Install the libraries and select the connected panel as described in the Chinese guide, then upload `mipi_dsi.ino`.

## Expected result

Color bars appear on the display.

## FAQ

Select the controller and timing that match the connected panel.
