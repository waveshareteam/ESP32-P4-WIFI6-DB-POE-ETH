# board_check

[简体中文](README_ZH.md)

## Function

Print chip, CPU, Flash, PSRAM and heap information.

## Hardware requirements

Development board and USB cable.

## How to run

Open `board_check.ino`, select the Waveshare board, upload it and open the serial monitor at 115200 baud.

## Expected result

The board information appears in the serial monitor.
