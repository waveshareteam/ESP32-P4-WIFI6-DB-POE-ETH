# sdmmc

[简体中文](README_ZH.md)

## Function

Read and write a test file on a microSD card using SDMMC.

## Hardware requirements

Development board and microSD card.

## How to run

Insert the card, upload `sdmmc.ino`, and open the serial monitor at 115200 baud.

## Expected result

Card information and the test file readback appear in the serial monitor.

## FAQ

The example writes `/arduino_test.txt` to the card root.
